# Battle-of-the-Interrupts-full-game

The goal of this project was to create a video game on an embedded system. 

We created an original game called "Battle of the Interrupts". The LCD screen would display a sequence of three numbers, and whoever pushed the three buttons in the order displayed on screen first, would attack the opposing player. The winning player would move the slide potentiometer to activate the attack animation.
